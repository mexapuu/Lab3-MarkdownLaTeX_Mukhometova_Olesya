## Лабораторная работа №3. Работа с MarkDown-разметкой и базовое использование LaTeX в документации проекта
#### Markdown (маркдаун) — это очень простой язык разметки, который нужен для форматирования текста обычными символами.
Главная особенностьТекст с разметкой Markdown легко читать прямо в исходном виде без специального софта, но при этом его можно быстро превратить в красивые страницы (например, в HTML или PDF). Вам не нужны сложные программы вроде Microsoft Word — достаточно любого блокнота.
#### Где применяется
Разработка и IT
Заметки и базы знаний
ИИ и нейросети
Блоги и сайты
Мессенджеры
#### Зачем он нужен разработчику
#### Разработчики постоянно работают с текстом, который должен быть простым, легким и удобным для совместной работы. Markdown решает сразу несколько задач:
Оформление документации (README.md). Почти каждый проект на GitHub или GitLab начинается с файла README.md. В нем программист описывает, что делает программа, как ее установить и запустить.
Контроль версий. Поскольку файлы .md — это обычный текст, системы контроля версий (например, Git) отлично отслеживают любые изменения в них. Видно каждую правку, строчку за строчкой.
Быстрое создание заметок. Разработчики используют Markdown-редакторы (Obsidian, Notion, VS Code), чтобы быстро конспектировать мысли, сохранять куски кода и инструкции без отвлечения на дизайн и верстку.
Интеграция с платформами. Разметка Markdown поддерживается в Jira, Trello, в комментариях на GitHub
